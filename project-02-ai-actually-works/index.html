AI is not magic. It's mathematics, data and patterns.

An interactive beginner-friendly guide to what actually happens when an AI system learns from data, makes predictions and generates something new.

From data to answer

Think of AI as a pipeline. Each stage transforms information until the system can produce a useful output.

01 · Data

Models learn from examples: text, images, audio, numbers and other information. Computers turn these inputs into numerical representations they can process.

02 · Training

The model makes predictions, measures how wrong they are, and adjusts its internal parameters. This happens over and over across many examples.

03 · Weights

Weights are adjustable numbers inside a model. Training changes them so useful patterns become more strongly represented.

04 · Inference

After training, the model receives new input and runs it through the learned parameters. This process is called inference.

05 · Prediction

The model calculates possible outputs and their relative likelihoods. For a language model, this can mean predicting what token is likely to come next.

06 · Output

The system turns those calculations into something humans can use: a classification, recommendation, image, sentence, answer or action.

The part people call “learning”

A model does not understand an example the way a person does. It adjusts numbers until its predictions become better at the task.

Prediction → error → adjustment

Imagine a model trying to identify a cat. It predicts 20% cat, but the training example is actually a cat. The training process calculates a loss that represents how bad the prediction was. An optimisation algorithm then nudges the model's parameters in a direction that should reduce that loss.

loss = how wrong the prediction is

Repeat this across huge numbers of examples and the model can gradually encode useful statistical patterns.

Gradient descent

One common optimisation method is gradient descent. It uses information about how the loss changes to decide which direction to move the parameters.

Backpropagation

In neural networks, backpropagation calculates how much different parameters contributed to the error, allowing the optimiser to update them efficiently.

Parameters

A modern neural network can contain an enormous number of learned parameters. They are numbers—not tiny rules written by a programmer for every possible situation.

Why scale matters

More data, compute and model capacity can allow systems to learn richer patterns, although more scale does not automatically make a model truthful or reliable.

How generative AI fits in

Chatbots and image generators are built from the same broad idea: learn patterns from large datasets, then use those learned patterns to generate outputs from new prompts.

Tokens

Language models break text into tokens—often pieces of words, words or punctuation. The model processes these numerical representations rather than reading text as a human does.

Next-token prediction

At a basic level, a language model repeatedly estimates what token should come next given the context. Repeating that process can produce paragraphs, code and conversations.

Temperature

Generation can be sampled in ways that favour the most likely choices or allow more variation. Higher randomness can produce surprising outputs, but it can also make them less predictable.

Why it can sound smart

Language contains enormous amounts of structure. A model that learns rich statistical relationships can produce remarkably coherent sequences without having human-like consciousness.

What AI still gets wrong

A powerful model can be useful without being an oracle. Its output is a calculation shaped by its training and the information available at inference time.

Hallucinations

A model can generate a plausible-sounding claim that is false. Fluency is not proof of accuracy.

Bias

Training data reflects the world it came from. If data contains gaps or biases, model behaviour can reproduce or amplify them.

Context limits

Models have finite context windows and can struggle when important information is missing, ambiguous or buried in very long input.

No guaranteed understanding

AI can manipulate complex representations and perform impressive tasks, but that does not by itself establish human-like consciousness or understanding.

The big idea

AI is a system for learning patterns from data and using those patterns to make calculations about new inputs. The interesting part is not that the machine has a little brain inside it. The interesting part is what happens when mathematics, data, algorithms and enormous amounts of computation are combined.
