How it works

Your pointer position determines the target inside the goal. The ball animates toward it while the keeper chooses a dive direction.

  • Hold Space to charge your shot, then release to kick.
  • More power means a faster shot, but timing matters.
  • 5 shots per game.
  • Score a goal to increase your total.
  • The keeper has a little randomness, so every game is different.

What this demonstrates

Pointer input, coordinate mapping, animation, game state, timing, hit detection and responsive interaction — all built with HTML, CSS and JavaScript. Pointer Events provide a single input model for mouse, pen and touch devices.
