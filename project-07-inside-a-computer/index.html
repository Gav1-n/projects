Interactive walkthrough / 01

What happens when you click?

A simple action sets off a chain reaction. Step through the path an instruction can take inside a computer. This is a simplified model — real systems overlap many operations.

🖱️InputA click or key press→
🧠CPUFetch and decode→
⚙️ProcessPerform operations→
🧩MemoryRead or write data→
🖥️OutputUpdate the screen
You click a button. The mouse or touchscreen sends an input signal to the computer, which the operating system and application interpret as an event.

Why two states?

On or off — reliably.

Transistors act like tiny electronic switches. A circuit can represent a 0 or 1 using different voltage ranges. Billions of transistors work together inside modern chips.

0 · LOWA voltage interpreted as the low state
1 · HIGHA voltage interpreted as the high state
BITOne binary digit — the smallest unit of digital data
BYTEEight bits — often used to represent a character or small value

The bigger picture / 04

Hardware meets software.

A computer is more than a processor. Different layers cooperate to turn human intentions into instructions the hardware can execute.

📱

Applications

The apps and games you use — they provide features and respond to your actions.

🧭

Operating system

Manages memory, files, devices and running programs; coordinates access to hardware.

🧰

Drivers & firmware

Help the operating system communicate with devices; firmware handles low-level device behaviour.

🧠

CPU

Executes general-purpose instructions, performs calculations and coordinates work.

🎨

GPU

Specialises in processing many operations in parallel, useful for graphics and other workloads.

🔌

Motherboard & buses

Connect components and provide pathways for data, control signals and power.
